# Cotons 기기 회수

병원 PC에 Sense 1 기기를 USB로 연결하면 진행 중인 재가치료 세션을 자동으로 회수하는 Windows 프로그램입니다.

이 저장소는 설치 파일 배포와 자동 업데이트 전용입니다. 소스 코드는 비공개 저장소에서 관리합니다.

## 지원 환경

- Windows 10, Windows 11 (64비트)
- 인터넷 연결 필요
- macOS 미지원

## 다운로드

1. [최신 릴리즈](https://github.com/dog-disease-ai/cotons-hospital-desktop-releases/releases/latest) 페이지 열기
2. `Assets` 에서 `CotonsHospitalDesktop-Setup-<버전>.exe` 다운로드

- `.blockmap`, `latest.yml` 파일은 자동 업데이트용 파일입니다. 다운로드하지 않아도 됩니다.

## 설치

1. 다운로드한 `CotonsHospitalDesktop-Setup-<버전>.exe` 실행
2. `Windows의 PC 보호` 경고 표시 시 `추가 정보` → `실행` 클릭
3. 설치 완료 후 프로그램 자동 실행

- 설치 화면 없이 바로 설치됩니다.
- 관리자 권한이 필요하지 않습니다.
- 설치 위치: `%LOCALAPPDATA%\Programs\cotons-hospital-desktop`
- 2번 경고는 코드 서명 인증서가 아직 없어서 표시됩니다.

## 로그인

1. 첫 실행 시 `서비스 계정 로그인` 창 표시
2. Cotons 담당자에게 받은 `client_id` 입력
3. Cotons 담당자에게 받은 `client_secret` 입력
4. `로그인` 버튼 클릭
5. 로그인 성공 시 메인 화면으로 전환

- 한 번 로그인하면 다음 실행부터 자동으로 로그인됩니다.
- 자격증명은 이 PC의 Windows 계정에 암호화해서 저장합니다.
- `client_secret` 은 병원 외부에 공유하지 않습니다.
- `자격증명이 맞지 않아요. 다시 입력해 주세요.` 표시 시 입력값 확인 후 다시 로그인합니다.

## 기기 회수

1. 재가치료가 끝난 Sense 1 기기를 USB 케이블로 PC에 연결
2. 프로그램이 기기 정보를 자동으로 읽고 진행 중인 세션 확인
3. 진행 중인 세션이 있으면 자동 회수
4. 화면 오른쪽 아래에 `<보호자 이름> 보호자님 기기를 회수했어요` 알림 표시

- 확인 버튼이 없습니다. 기기 연결만 하면 됩니다.
- 진행 중인 세션이 없는 기기는 알림 없이 넘어갑니다.
- 인터넷 연결이 끊긴 상태에서 연결한 기기는 `재시도 중` 으로 기록되고, 인터넷 연결 복구 후 자동으로 회수합니다.

## 프로그램 창

- 작업 표시줄 오른쪽 알림 영역(시계 옆)의 Cotons 아이콘 클릭 시 창 표시
- 창을 닫아도 프로그램은 계속 실행되고 회수도 계속 동작합니다.
- 아이콘 오른쪽 클릭 메뉴: `설정 열기`, `종료`
- `종료` 후에는 기기를 연결해도 회수하지 않습니다. 다시 사용하려면 시작 메뉴에서 `CotonsHospitalDesktop` 실행

| 구역 | 내용 |
|---|---|
| 현재 컴퓨터에 연결된 기기 목록 | 지금 연결된 기기의 러버 시리얼과 기기 번호 |
| 최근 회수 기록 | 최근 10건의 시각, 러버 시리얼, 반려견 이름, 결과 |

| 결과 | 의미 |
|---|---|
| 회수함 | 세션 회수 완료 |
| 이미 끝남 | 다른 곳에서 먼저 회수된 세션 |
| 재시도 중 | 인터넷 연결 오류로 자동 재시도 대기 |
| 실패 | 회수 실패. Cotons 담당자에게 문의 |

## 자동 실행

- PC를 켜고 Windows에 로그인하면 창 없이 자동으로 실행됩니다.
- 작업 관리자 → `시작 앱` 에서 `CotonsHospitalDesktop` 이 `사용` 상태인지 확인할 수 있습니다.

## 자동 업데이트

- 1시간마다 새 버전 확인 후 자동 다운로드
- 기기가 연결되어 있지 않고 회수가 진행 중이 아닌 상태가 1분 이어지면 자동 설치 후 재실행
- 설치 중에는 창이 표시되지 않습니다.
- 사용자 조작이 필요하지 않습니다.
- 위 조건이 충족되지 않으면 PC 종료 시 설치됩니다.
- 설치 전에 대기 중이던 `재시도 중` 기록은 재실행 후 이어서 처리합니다.

## 로그아웃

1. 창 오른쪽 위 프로필 아이콘 클릭
2. `로그아웃` 클릭

- 로그아웃 상태에서는 기기를 연결해도 회수하지 않습니다.

## 문제 해결

| 화면 문구·증상 | 조치 |
|---|---|
| `COM<번호> 기기를 읽지 못했어요. 다시 꽂아 주세요.` | 기기를 사용하는 다른 프로그램(데이터 다운로더 등) 종료 후 USB 케이블 재연결 |
| `COM<번호> 기기는 회수할 수 없는 예전 기기예요.` | 이 프로그램으로 회수할 수 없는 구형 기기. Cotons 담당자에게 문의 |
| `재시도 중` 이 계속 유지됨 | PC 인터넷 연결 확인 |
| 로그인 창이 다시 표시됨 | 자격증명 변경 또는 만료. Cotons 담당자에게 새 자격증명 요청 |
| 알림이 표시되지 않음 | Windows 설정 → 시스템 → 알림 에서 `Cotons 기기 회수` 알림 허용 |

## 삭제

1. Windows 설정 → 앱 → 설치된 앱
2. `CotonsHospitalDesktop` 선택
3. `제거` 클릭
